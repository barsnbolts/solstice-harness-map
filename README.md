# Solstice E69 → Link G5 Voodoo Pro V2

Interactive engineering review draft. All 154 OEM and 94 Link cavities are visible. Hover traces connections, circuit focus keeps physical positions stable, colour coding distinguishes circuit families or allocation status. Open positions are grouped by input/output capability and separated into spare, reserved and dedicated.

**Not an as-built or energize-ready pinout.** Vehicle year, installed ECU label, physical continuity, OEM orientation and mating-header keying remain unverified. New PI wiring is separate; stock DI/HPFP power wires remain isolated. Future DI requires a compatible external driver and characterization. No spare pin is assumed universally interchangeable.
